# task9
Descriptive Statistics: Employee Compensation & Performance

Project Overview

This project completes Task 9 -- Descriptive Statistics Primer from
the Data Analytics Track. The analysis calculates and interprets mean,
median, mode, standard deviation, percentiles, and skewness for key
numeric columns.

Objective

Build practical intuition for when each descriptive statistic should be
used and what it reveals about a dataset's distribution.

Dataset

Records: 80

Numeric columns: Experience_Years, Annual_Salary_LPA,
Performance_Score, Training_Hours

Categorical/context columns: Employee_ID, Department, City

Analysis Performed

For every selected numeric column: - Mean - Median - Mode - Standard
deviation - 25th percentile (P25) - 50th percentile (P50 / Median) -
75th percentile (P75) - Minimum and maximum - Skewness

Key Interpretation Approach

Mean vs Median: helps identify skew.

Standard deviation + Mean: describes relative spread.

P25--P75: represents the middle 50% of observations.

Skewness: indicates the direction and strength of asymmetry.

Tools

Python

Result

The workbook contains: 1. Raw dataset 2. Summary statistics table 3.
Interpretation guide 4. Mean vs standard deviation chart

Learning Outcome

This task strengthened practical understanding of descriptive statistics
and how summary measures can explain the center, spread and shape of a
distribution.
